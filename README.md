# Использование

Перед запуском необходимо добавить файлы .env и .env.postgres в корень репозитория. Файлы используются для настройки бэкенда и БД соответственно. В .env обязательно должны присутствовать SECRET_KEY (секретный ключ для шифрования токенов) и DATABASE_URL (URL для подключения к БД).

См. .env.example и .env.postgres.example
